# AI Finance Controller - Merchant Portal (Frontend)

A modern, responsive financial merchant portal dashboard featuring:
- **Real-Time Financial Metrics**: Total payment volume, reconciliation match rates, failed payment counts, and risk-rated transactions.
- **Razorpay Checkout Integration**: Interactive checkout testing with client-side verification and status management.
- **Automated Ledger Reconciliation**: Table tracking discrepancies between internal order values and payment gateway receipts with one-click resolution.
- **Failed Payment Recovery**: Automated smart retry actions for stalled or failed transactions.
- **AI Financial Copilot**: Integrated conversational copilot powered by Google Gemini for financial ledger insights, performance analysis, and risk auditing.

## Tech Stack
- HTML5 & Modern Vanilla JavaScript
- Tailwind CSS (CDN)
- Lucide Icons
- Google Fonts (Inter & JetBrains Mono)
- Razorpay Checkout SDK

## Getting Started
Simply open `index.html` in any modern web browser or serve it with any static web host (such as GitHub Pages, Vercel, or Netlify).
